# 📊 EDA Retail Business Analysis Using Python

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of retail sales data to understand business performance, sales patterns, regional profitability, discount behavior, and customer payment preferences.

## 🎯 Objectives
- Understand and validate the retail sales dataset.
- Identify data-quality issues and prepare the data for analysis.
- Analyze sales and profit across regions and product categories.
- Explore the relationship between discounts and profit.
- Understand customer payment preferences.
- Identify sales trends and derive business insights.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Files
- `EDA_Retail_Business_Analysis.ipynb` — Notebook containing data cleaning, analysis, and visualizations.
- `retail_sales_cleaned.csv` — Cleaned dataset used for analysis.

## 🔍 Analysis Performed
- Data understanding and quality validation
- Missing-value and duplicate checks
- Indexing, slicing, filtering, sorting, and grouping
- Aggregation using Pandas
- Univariate, bivariate, and multivariate analysis
- Sales and profit distribution analysis
- Regional and category comparisons
- Discount and payment-method analysis
- Monthly sales trend analysis

## 💡 Business Questions
- Which product categories generate the highest sales?
- Which regions and cities generate the highest profit?
- How are discounts associated with profit?
- Which payment methods are used most frequently?
- How do sales trends change over time?

## 📈 Key Findings
The analysis calculates total sales and profit, compares category and regional performance, identifies payment preferences, and explores discount patterns. All findings are derived from the supplied dataset.

## ▶️ How to Run
1. Download or clone this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

3. Keep the notebook and CSV file in the same folder.
4. Open `EDA_Retail_Business_Analysis.ipynb` in Jupyter Notebook or VS Code.
5. Run the notebook cells in order.

## 📝 Conclusion
This project demonstrates the use of Python for data cleaning, exploratory analysis, visualization, and business insight generation.
